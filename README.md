# metanorma-plugin-asyncapi

Renders [AsyncAPI](https://www.asyncapi.com) documents as normative
Metanorma sections — the `[asyncapi,path=...]` preprocessor and
renderer over [lutaml-asyncapi](https://github.com/lutaml/lutaml-asyncapi).

```adoc
[asyncapi,path=asyncapi.yaml]
--
--
```

See PLAN.md at lutaml-asyncapi for the program.
